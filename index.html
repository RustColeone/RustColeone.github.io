ImageDB

Local-first image vault  ·  Android + Web

A private, searchable image database where you own every byte. Import images, label them with captions, albums, and free-form tags, then search and browse them completely offline — no accounts, no cloud, no uploads to third-party servers.

Organising — Albums, free-form tags with autocomplete drawn from every tag ever used, captions, and live full-text search across captions and tags. Filter the feed by one or more tags, file type (GIF vs still), or album. A Tag Manager lets you rename or delete tags globally.

Adding images — FAB button, hold-for-camera (0.5 s hold with ring animation), drag & drop onto the drop zone, paste from clipboard (Ctrl+V), receive from the Android share sheet, or batch import wizard. The batch wizard lets you set caption, album, and tags per image and supports bulk-editing shared fields across the whole batch.

Viewing — Responsive masonry grid (2–4+ columns). GIF files get a badge. Long-press or right-click a card for a context menu. Detail view is a swipeable card — swipe left/right to navigate to adjacent images with a ghost preview sliding in from the side. Lightbox with scroll-to-zoom, pinch-to-zoom, double-tap, and drag-to-pan. Pinch outward on the thumbnail in the detail view to transition directly into the lightbox.

Editing & actions — Edit metadata, delete (single or multi-select), copy to clipboard (native Android content:// URI via FileProvider), save to phone, share via system sheet, crop & share. Crop supports animated GIF output for GIFs (using gifenc). Multi-select mode with select-all, invert, delete, and batch-edit actions.

Data portability — Export the entire vault as a ZIP (images, thumbnails, and a JSON metadata file). Import ZIP is merge-safe and idempotent — entries with the same ID are skipped, so re-importing never duplicates blobs.

Appearance — Dark/light mode toggle. Warm dark theme by default. Setting persists across sessions.

Images and thumbnails live in a layered blob store: Capacitor filesystem on Android (app-private, invisible to the gallery), OPFS on modern browsers (Chrome 102+, Firefox 111+, Safari 15.2+), and IndexedDB as a legacy fallback. On upgrade, blobs migrate transparently from IndexedDB to OPFS.

Metadata, the hashbook, and settings are stored in SQLite compiled to WebAssembly via sql.js. The database file is persisted to OPFS after every write via a debounced 150 ms flush. SHA-256 deduplication (via crypto.subtle.digest) maps every image hash to a blob ID — importing the same file twice reuses the existing blob.

Storage layout: images/<blobId>.<ext>, thumbs/<blobId>.jpg, imagedb.sqlite.

Frontend — Single HTML file, no build step. HTML, CSS, and JavaScript all co-located. www/index.html is a generated artefact stamped with the version from package.json.

Native shell — Capacitor for Android. Two custom Java plugins extend the bridge:

  ClipboardImagePlugin — Writes a full-resolution image to the Android clipboard as a content:// URI backed by FileProvider, so other apps (WhatsApp, Telegram, etc.) can paste actual pixels rather than a data URL.

  SharePlugin — Captures images shared into ImageDB from other apps. Exposes getPendingShare() to JS, which returns the image base64-encoded so the entry dialog opens with it pre-loaded.

Libraries — sql.js 1.10.3 (SQLite/WASM), fflate 0.8.2 (ZIP compress/decompress), gifenc 1.0.3 (animated GIF crop export), Capacitor filesystem, camera, share, clipboard, and app plugins.

NeuroCamp

Brain training game collection  ·  Android

A collection of interactive brain training games designed to improve cognitive reflexes, focus, and mental agility. Each game runs independently while being accessible through a unified navigation hub. Fully offline — no accounts, no cloud, no data collection.

Schulte Table — A visual attention and processing speed game. Find and click numbers in sequential order on a grid. Improves peripheral vision and visual scanning speed.

Stop Signal — A reaction time and impulse control game. Respond quickly to go signals while inhibiting responses to stop signals. Trains executive control and quick decision-making.

Camp Chord Scout — An ear training game. Listen to synthesized chords and identify them by name. Builds auditory discrimination and musical interval recognition via in-browser Web Audio synthesis.

Animal Memory Ranger — A memory match game. Study animals with randomized profiles (name, favorite color, habitat, appetite), then answer quiz questions to match each animal.

Rhythm Sync Test — A rhythm timing game. Birds count in for several beats before audio cuts out — tap exactly on the next silent beat.

Frontend — Pure HTML, CSS, and JavaScript. No frameworks, no build step. Nine standalone HTML files with a shared UI/SFX module.

Native shell — Capacitor 8 for Android. www/ is a generated artefact populated by a prepare-web.js script that stamps the version from package.json into the hub page.

Design — Camping-themed UI with dark/light mode toggle. Theme changes propagate to loaded games via postMessage. Responsive layout with back-navigation support.

DoraemonDB

Manga panel search engine  ·  Python + Flask

A local full-text and semantic search engine over a scanned Doraemon manga collection. 61,565 panels extracted from ZIP archives, OCR'd with PaddleOCR, enriched with AI-generated semantic tags, and embedded with a local language model — all served through a Flask web UI running entirely on your own machine.

1. Panel extraction — extract_storyboards.py reads every manga page from ZIP archives, runs flood-fill/contour analysis to detect individual panels, then PaddleOCR to extract Chinese text. Results go into SQLite: source path, page name, panel index, OCR text, and the path inside the ZIP for image serving.

2. DB migration — migrate_add_tags.py adds tags, tags_model, embedding, and embedding_model columns to the panels table and creates the tag_vocab global tag vocabulary. Safe to re-run (idempotent).

3. Tag enrichment — enrich_tags.py calls DeepSeek Chat (deepseek-chat) for each un-tagged panel to produce 5–15 candidate Chinese semantic tags (e.g. 哭泣, 大雄, 道具). Each candidate is deduplicated against the global tag_vocab using BAAI/bge-m3 cosine similarity at a 0.90 threshold — close matches reuse the canonical vocab tag; new ones are added. Requires DEEPSEEK_API_KEY.

4. Embedding build — build_embeddings.py encodes every panel into a 1024-dim float32 vector using BAAI/bge-m3 (sentence-transformers) and stores it as a BLOB. Embedding source priority: canonical tags if available, otherwise raw OCR text. One-time offline step (~60 min on CPU for 61k panels).

Flask server at localhost:5051. On first request it loads all embedding BLOBs into a numpy float32 matrix in memory (~10 min refresh) and caches the tag vocabulary (~5 min refresh).

The unified search endpoint (/api/search/unified) combines three modes, each contributing a normalised 0–1 score per panel:

  词 (keywords) — always-on; matched_terms / total_terms against OCR text.

  意 (vector) — cosine similarity via dot product on L2-normalised bge-m3 embeddings. Default ON.

  AI (semantic) — DeepSeek Chat maps the query to vocab tags; matched_query_tags / total_query_tags. Default OFF.

Combined score = sum of active method scores, normalised to 0–100% by the number of active methods. Results sorted descending. Negative exclusions (-term) work across all methods.

Single-page app, no build step. Search row with text input, regex toggle (.*), and search button. Filter row with 意 (vector, default ON), AI (DeepSeek semantic, default OFF), series dropdown, and character-count filter. 词 (keywords) is always-on but hidden.

Result cards show extracted text, tag chips (matched tags highlighted), and a score badge: 75% 词82·意60 for unified mode, 完全匹配 for exact phrase, 相似 XX% for vector-only. Lightbox with crop and copy-to-clipboard support.
